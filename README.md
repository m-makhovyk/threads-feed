# Threads Feed

Experimental iOS project — reimplementing a Threads-like feed with media preview, full-screen viewing, and animations.

## Roadmap

### Image feed
- [x] Feed with image attachments
- [x] Full-screen image preview
- [x] Custom transition to full-screen preview
- [x] Swipe to dismiss
- [x] Pinch to zoom

### Video feed
- [ ] Feed with video attachments
- [ ] Full-screen video preview
- [ ] Custom transition to full-screen preview
- [ ] Swipe to dismiss

### Mixed feed
- [ ] Feed with mixed (image + video) attachments
- [ ] Full-screen preview supporting both media types
